# IoT-Based Intelligent System for Laboratory Safety Monitoring

## ระบบเฝ้าระวังความปลอดภัยในห้องปฏิบัติการด้วย IoT และ AI

โครงงานต้นแบบสำหรับช่วยเฝ้าระวังเหตุการณ์เสี่ยงในห้องปฏิบัติการ โดยใช้กล้องวงจรปิดร่วมกับ AI เพื่อตรวจจับเปลวไฟและควันจากภาพ แล้วส่งผลไปยังระบบบันทึกเหตุการณ์และ Dashboard

## แนวคิดระบบ

```text
กล้องวงจรปิด -> AI ตรวจจับ -> Server/API -> Dashboard และการแจ้งเตือน
```

เมื่อพบเหตุการณ์ ระบบสามารถบันทึกภาพ Snapshot และวิดีโอหลักฐานช่วงก่อนและหลังเหตุการณ์ เพื่อช่วยให้ผู้ดูแลตรวจสอบได้ง่ายขึ้น

## ความสามารถที่สาธิต

- ตรวจจับเปลวไฟและควันจากภาพวิดีโอ
- แสดงภาพกล้องพร้อมผลการตรวจจับ
- บันทึกเหตุการณ์และจัดระดับความเสี่ยง
- แสดงเหตุการณ์ล่าสุดบน Dashboard
- บันทึกภาพและคลิปหลักฐานของเหตุการณ์
- รองรับการแจ้งเตือนภายนอกเมื่อเกิดเหตุการณ์สำคัญ

## เทคโนโลยี

- Python และ OpenCV
- YOLO สำหรับตรวจจับวัตถุ
- Flask สำหรับ Server และ API
- SQLite สำหรับจัดเก็บเหตุการณ์
- HTML, CSS และ JavaScript สำหรับ Dashboard

## โครงสร้างการทำงาน

1. รับภาพจากกล้องหรือวิดีโอทดสอบ
2. ประมวลผลภาพด้วยโมเดล AI
3. ตรวจสอบเหตุการณ์และระดับความเสี่ยง
4. ส่งข้อมูลไปยัง Server
5. แสดงผลบน Dashboard และจัดเก็บหลักฐาน

## ตัวอย่างโค้ด

ดูตัวอย่างการทำงานของ AI Detection, API และการแจ้งเตือนได้ที่ [docs/code-examples.md](docs/code-examples.md)

## ขอบเขตของ Repository นี้

Repository นี้จัดทำขึ้นสำหรับนำเสนอแนวคิดและผลการพัฒนา จึงไม่รวมข้อมูลลับ เช่น รหัสผ่านกล้อง URL เชื่อมต่อจริง Webhook ไฟล์ `.env` และโมเดลขนาดใหญ่

## ข้อจำกัด

ความแม่นยำขึ้นอยู่กับมุมกล้อง ระยะห่าง แสง และคุณภาพของข้อมูลฝึก โมเดลควรได้รับการทดสอบกับสภาพแวดล้อมจริงเพิ่มเติมก่อนใช้งานเป็นระบบความปลอดภัยหลัก
